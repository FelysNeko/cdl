# Coded Deep Learning

This is an unofficial implementation of [Coded Deep Learning: Framework and Algorithm](https://arxiv.org/abs/2501.09849) with additional NVFP4, MXFP4, and MXFP8 support. The ultimate goal is to pre-train large language model in low-precision but retain high-precision performance. Additionally, this method should bring faster training and inference speed.
